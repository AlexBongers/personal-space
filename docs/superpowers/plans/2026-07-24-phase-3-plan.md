# Phase 3 Implementation Plan — Databases and the Table View

**Goal:** Implement database pages with typed properties, rows, table view, and row-as-page view.

**Architecture:** Express API routes for databases, properties, rows, cell values. React components for table view, property editors, and row page. Properties table already exists in schema.

**Tech Stack:** Express, better-sqlite3, React, react-datepicker, react-colorful

## Global Constraints
- No emojis in code, comments, print statements or logging. Emoji page icons are a feature.
- Keep it simple: small modules, clear names, no defensive programming, no overengineering.

---

### Task 1: Database API Routes

**Files:**
- Create: `server/src/routes/databases.ts`
- Modify: `server/src/index.ts` (mount databases router)
- Create: `server/tests/databases.test.ts`

**Endpoints:**
- `GET    /api/databases/:id` — full database with properties, rows, cells
- `POST   /api/databases/:id/properties` — add property { name, type, options? }
- `PUT    /api/properties/:id` — rename { name? }, update options { options? }
- `DELETE /api/properties/:id` — remove (cascades)
- `PUT    /api/properties/:id/reorder` — reorder { propertyIds }
- `POST   /api/databases/:id/rows` — add row { title? }
- `PUT    /api/rows/:id` — rename { title? }
- `DELETE /api/rows/:id` — delete (cascades)
- `PUT    /api/rows/:id/reorder` — reorder { rowIds }
- `PUT    /api/cells/:id` — update cell value
- `PUT    /api/rows/:id/cells` — batch update cells

**Tests:** Create/read/update/delete properties, rows, cells. Use supertest.

### Task 2: Database View + Table View Components

**Files:**
- Create: `client/src/components/DatabaseView.tsx` (view switcher shell)
- Create: `client/src/components/TableView.tsx` (table grid)
- Create: `client/src/components/PropertyEditor.tsx` (cell editors per type)
- Modify: `client/src/App.tsx` (route database pages to DatabaseView)
- Modify: `client/src/api.ts` (add database API functions)

**Components:**
- DatabaseView: fetches database data, renders view switcher and active view
- TableView: column headers, editable cells, add/delete row buttons
- PropertyEditor: renders different editors based on property type (text input, number input, date picker, checkbox, select dropdown, multi-select with colors, URL input)

**Property editors:**
- text: `<input type="text">`
- number: `<input type="number">`
- select: dropdown with colored options
- multi_select: multi-select with colored chips
- date: `<input type="date">`
- checkbox: `<input type="checkbox">`
- url: `<input type="url">`
