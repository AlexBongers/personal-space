# Phase 4 Implementation Plan — Board, List, Filters, Sorts

**Goal:** Add board and list views, view switcher, filters, and sort to databases.

**Architecture:** View settings stored as JSON in `view_settings` table. Board view groups by select property. List view shows compact rows. Filters and sort apply to all views.

**Success criteria:**
1. Each database switches between table, board and list in place
2. Board groups rows by select property, one column per option
3. Dragging a card to another column changes property value
4. Filters narrow rows, sort orders by property
5. Settings persist per view
6. List view shows title + at least one property

---

### Task 1: View Settings API + View Switcher

- Create `PUT /api/databases/:id/views/:viewType` to save settings (filters, sort, groupBy)
- Get `GET /api/databases/:id/views` to load them
- Create `client/src/components/ViewSwitcher.tsx` — tab bar (Table / Board / List)
- Modify `DatabaseView.tsx` to use view switcher and render active view
- Add view API functions to `client/src/api.ts`

### Task 2: Board View

- Create `client/src/components/BoardView.tsx` — columns for each select option
- Cards show row title, drag to another column changes the grouping property value
- Uses HTML5 drag-and-drop (reuse pattern from DragHandleExtension)
- Grouping property selector: dropdown to choose which select property to group by

### Task 3: List View

- Create `client/src/components/ListView.tsx` — compact list of rows
- Each row shows title + first property value
- Click row to navigate to row page

### Task 4: Filters and Sort

- Create `client/src/components/FilterBar.tsx` — add/remove filter rows
- Create `client/src/components/SortControl.tsx` — property + direction
- Filter types: text contains, select is/is not, checkbox checked, date before/after
- Sort: by any property, ascending/descending
- Filters applied client-side (data already loaded)
- Persisted to view_settings

### Task 5: Seed + E2E

- Modify seed: add view settings to existing databases
- E2E: switch views, apply filter, sort, drag board card
