# Phase 5 Implementation Plan — Search, Dark Mode, Full Workspace

**Goal:** Add quick-find search, theme toggle UI, and complete the seed workspace.

**Success criteria:**
1. Quick-find opens by Ctrl+K and visible control; typing narrows live; choosing navigates
2. Theme toggle switches between light/dark; persists
3. Full workspace seed demonstrates every feature
4. Unit tests for search pass
5. E2E tests cover search and theme toggle

---

### Task 1: Search API + QuickFind component

- Create `GET /api/search?q=...` route in `server/src/routes/search.ts` — searches page, database, row titles
- Create `client/src/components/QuickFind.tsx` — modal overlay with search input
- Opens with Ctrl+K (or Cmd+K on Mac) and a visible search button in the header
- Results appear live as you type (debounced 200ms)
- Use arrow keys to navigate results, Enter to select, Escape to close
- Clicking a result navigates to that page
- Add search API function to `client/src/api.ts`

### Task 2: Theme Toggle UI

- Create `client/src/components/ThemeToggle.tsx` — button in the top-right corner
- Toggles between light/dark using the existing theme store
- Persist choice to server via `PUT /api/theme`
- Add theme API endpoints to `server/src/routes/pages.ts` or a new settings route

### Task 3: Full Seed Workspace

- Extend seed data to ensure every feature is demonstrated
- Add pages with all block types (already done in Phase 2)
- Add databases with all property types (already done in Phase 3)
- Add view settings for board view (already done in Phase 4)
- Ensure seed data is comprehensive

### Task 4: E2E Tests

- `e2e/phase-5-search-theme.sh` — search for a page, navigate to it, toggle theme, take screenshots
- Update run-all.sh
