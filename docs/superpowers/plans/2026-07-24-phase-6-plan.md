# Phase 6 Implementation Plan — Final Quality Gate

**Goal:** Ensure the product meets all quality, coverage, look-and-feel, and adversarial review criteria.

**Success criteria:**
1. 80%+ statement coverage on frontend and backend
2. Full E2E suite passes
3. Complete walkthrough with screenshots in both themes, no console errors
4. Adversarial review completed, findings fixed or rejected
5. Suites rerun after fixes
6. Look-and-feel rules met, avoid-list absent

---

### Task 1: Coverage Analysis

- Run `npx vitest run --coverage` on server
- Run `npx vitest run --coverage` on client
- Report current coverage percentages
- Add missing tests to reach 80%+ on both

### Task 2: Full E2E Walkthrough

- Run all E2E tests: `bash e2e/run-all.sh`
- Verify all pass
- Take screenshots of every screen in both themes
- Check for browser console errors during walkthrough

### Task 3: Look-and-Feel Pass

- Verify palette colors are used correctly (amber #ecad0a, blue #209dd7, purple #753991)
- Verify no overuse of gradients
- Verify no purple-dominated backgrounds
- Verify no thin accent borders down one side
- Check both themes are presentable
- Fix any violations

### Task 4: Adversarial Review

- Use the app in unscripted, hostile ways:
  - Create pages with very long titles
  - Create deeply nested pages
  - Delete databases with many rows
  - Type special characters in the editor
  - Rapidly toggle theme
  - Search for nonexistent terms
  - Add many properties to a database
  - Test edge cases
- Record findings with steps to reproduce
- Fix or reject each finding

### Task 5: Final Test Run

- After all fixes, run full test suites
- Run full E2E suite
- Verify everything passes
